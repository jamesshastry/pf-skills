# Mortgage review

## Mortgage insurance is the free money

If loan-to-value has fallen below the removal threshold and mortgage insurance
is still being paid, that is a pure recurring loss.

**Removal is frequently not automatic.** Request-based schemes require the
borrower to ask, and may require an appraisal. Because nobody sends a letter
about it, households pay it for years past the point it was required. Check
this first — it costs one phone call and needs no decision.

## Prepayment is a guaranteed return

Paying extra against a mortgage earns exactly the mortgage rate, guaranteed,
tax-adjusted if the interest is deductible.

Present it the same way `debt-payoff-priority` does, because it is the same
argument: **the comparison against investing is a certain return against an
uncertain one**, which is not like-for-like. Reasonable people take the
guaranteed return even when expected value favours investing. That is a
preference, not an error, and saying so is more useful than pushing.

The report shows the term reduction and interest saved so the trade-off is
concrete rather than abstract.

## Refinancing is a break-even, not a rate comparison

Divide closing costs by the monthly saving. Under about three years, it is
usually clear. Beyond that it depends entirely on how long they will stay —
same structure as `rent-vs-buy`, and the same mistake is available.

**Watch the term reset.** Refinancing a loan with twenty years remaining into a
fresh thirty-year term lowers the monthly payment while *increasing* total
interest. That is a cash-flow decision, and it can be a perfectly good one —
but it is routinely sold as a saving, and it is not one. Name it.

## Closing

1. **PMI first**, if removable. Cheapest win available.
2. **Prepayment framed honestly** — guaranteed return, with the certainty
   asymmetry.
3. **Refinance as a break-even**, with the term-reset warning.
4. **One next action.**
